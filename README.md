# 加油！专注工作记录（Focus Work Log）

一个**只在自己这台 Windows 电脑上运行**的本地网页应用，用来记录「我每天实际干了多久、干了什么」，
按柳比歇夫式的时长台账自动汇总，给出日/周/月反馈、目标达成率与连续达标天数，
用来了解自己的真实工作情况、自我鼓励、自我督促。

- **完全离线**：不联网、不登录、不引用任何外部资源（没有 CDN、没有外链字体图片）。
- **数据全在自己电脑上**：一个 SQLite 文件 `data/focus.db`，随时能找到、能备份、能导出 Excel。
- **零第三方依赖**：只用电脑上已有的 Python 3 标准库，不需要 `pip install`，不需要联网装东西。
- 每天自动备份、删除可恢复、最近 20 步操作可撤销。

---

## 快速开始

1. 装好 **Python 3**（3.8 以上即可，Windows 上安装时记得勾选 `Add python.exe to PATH`）；
2. **双击 `启动.bat`**；
3. 浏览器会自动打开 <http://127.0.0.1:8090/>。

启动器会做这些事：检查是否已有实例在跑 → 找空闲端口（从 8090 起，**永不使用 3080**）→
用 `pythonw.exe` 把服务放到**独立后台进程**里（所以启动窗口可以直接关掉）→ 打开默认浏览器。
如果 8090 被占用，会自动换 8091、8092…… 并在「启动日志.txt」里写明实际地址。

手工启动：`python run.py`（前台运行、能看到日志）。
停止软件：任务管理器结束 `pythonw.exe`，或重启电脑。

## 怎么录入

### 实时计时（首页）

选好**大类 + 二级任务 + 标签**（三项缺一不可）→ 点「▶ 开始计时」。点「停止并保存」直接落库，不弹窗追问。

- **可以并行计时**：不同任务各开一个计时器，互不影响。
- **关掉网页也照样在走**：计时状态存在后端数据库里，关掉浏览器甚至重启电脑，下次打开还在计时。
- **点「暂停」的那段时间不计入时长**。
- **跨午夜自动切开**：23:30 开始、01:00 才停，会记成昨天 23:30–23:59 一条、今天 00:00–01:00 一条。
- **忘记停止**：单段超过 4:00 时，下次打开会弹窗让你选「保留到实际时长 / 截断到某个时间点 / 删除这段」
  （阈值可在设置里改）。
- **快速开始**：首页会记住上一次用的大类/任务/标签，一键复用。
- 二级任务不在下拉里？下拉框右边有 **「＋新增」**按钮（下滑最下面那行「＋ 新建一个任务…」也一样），
  当场建、建完自动选中。重名会提示「这个任务已经存在。」并选中已有的那条，不会建出两条一样的。

### 事后补录（「记录」页）

填**日期 + 大类 + 二级任务 + 标签**，然后**时长**或**时间段**至少填一种：

| 填法 | 结果 |
|---|---|
| 只填**时长**（如 `3:30`） | 普通记录，没有时间段 |
| 只填**起始 + 终止时间**（如 `9:30` ~ `11:00`） | 时长自动算出来，并带上这段时间 |
| **两个都填** | 会核对是否一致；**对不上则报错、不保存**（提示会写出两个数分别是多少） |

时间段的规则：**起止必须成对填**；24 小时制；必须在所选日期当天 `00:00~23:59` 之内（不能跨天），
终止时间不能晚于现在；**填了时间段的记录会参与"时间轴去重"**（与当天其它带时间的记录重叠部分只算一次），
只填时长的记录则直接相加、不参与去重。

其他：时长写法很宽松（`3:30`、`1h46m`、`106`、`1.5h`、`1小时46分`）；内部按整数分钟存，显示是 `H:MM`；
可以顺带记产出物（文档/代码/实验/图表/其他 + 名称 + 链接）；**不能补录未来日期**。

### 空白日补录

没记录的日子在「记录」页会标成橙色「未记录」，点那一行就能直接补。首页打开时也会提示最近几天哪天没记录。

## 怎么设目标

「设置 → 目标设置」里给每个大类分别填：

| 项目 | 说明 |
|---|---|
| 工作日目标 | 周一~周五用这个数 |
| 周末目标 | **周日**用这个数 |
| 周六 | 自动 = 工作日目标 × 比例（默认 50%，可改） |

填 `H:MM`（如 `3:00`）或分钟数（如 `180`）；**留空表示这个大类不参与达标判定**。
填完记得点「保存目标」。**软件不预设任何目标数字**，一个都没设时，达成率/连续达标模块会自动隐藏并提示你。

- **达标日** = 当天所有「已设目标的大类」都达到各自当日目标（有一门没到就不算）。
- **连续达标天数** = 从最近一天往前连续达标的天数，**中断一天即清零**；
  如果「今天」还没达标，不把今天算作中断。

## 怎么导出 Excel

「设置 → 导出 Excel」：选起止日期、勾选要**排除**的大类（例如只导出科研+会议给别人看），
点「导出到 export/」。导出的 `.xlsx` 有 4 个 sheet：

| sheet | 内容 |
|---|---|
| 明细表 | 一行一条记录：日期/星期/大类/二级任务/标签/时长(H:MM)/时长(小数)/备注/产出物/来源/起止时间 |
| 日汇总表 | 一行一天，按大类分列 + 总计 + 工作时间（科研+会议）+ 是否达标 + 条数 |
| 汇总页 | 按二级任务聚合、按大类聚合、按月度统计（两种平均每天、记录率、达标天数） |
| 图表页 | 每日趋势、大类占比、Top 任务、月度对比（单元格字符条形图，不依赖任何组件） |

导出**不联网**，也不下载任何组件（`app/xlsx.py` 用标准库 `zipfile` 手写 XML）。

## 怎么备份与恢复

| 内容 | 位置 |
|---|---|
| **数据文件（每天在用）** | `data/focus.db` |
| 每日自动备份 | `backup/`（保留最近 30 份，份数可改） |
| 周报/月报（.md） | `reports/` |
| 导出的 Excel | `export/` |

- **备份**：打开软件时会检查，当天没备份就自动做一份；也可在「设置 → 备份与恢复」点「立即备份」。
  备份用 SQLite 官方备份接口做快照，正在写入时也一致；超过保留份数的自动清理。
- **恢复**：在列表里找到那一份点「恢复」，勾选确认框再确认。恢复前**当前数据库会先被改名留档**
  （`data/focus.db.before_restore_时间戳`），恢复错了还能改回来。
- **手工恢复**（软件打不开时）：把 `backup/focus_xxxx.db` 复制成 `data/focus.db` 覆盖（覆盖前先把原来的改名留档）。
- **删错了**：「记录」页底部有**回收站**；「设置 → 撤销」可撤销最近至少 20 步操作。

## 统计口径

1. **各大类时长** = 该大类当天所有记录时长**直接相加，不去重**。
2. **实际时长（去重）** = 当天所有**带起止时间的记录**的区间**并集长度** + 当天所有**没有起止时间的记录**时长之和。
3. **投入时长之和** = 当天所有记录时长直接相加（参考值，并行时会大于实际时长）。
4. **首页大字** = 今日「计入工作时间」的大类（默认**只有科研 + 会议**）的实际时长（去重），
   这两个大类是**合并起来做区间并集**的。
5. **平均每天（记录日）** = 周期总时长 ÷ 该周期**有记录的天数**。
6. **平均每天（自然日）** = 周期总时长 ÷ 该周期**自然日天数**。
7. **记录率** = 有记录天数 ÷ 自然日天数。
8. 周报周期固定**周一~周日**；月报是**自然月**。
9. 「计入工作时间」可以对每个大类单独开关（新增大类默认**否**）。

## 周报 / 月报

- **打开软件时自动补生成**「上一个已结束的周」和「上一个已结束的月」，存进 `reports/`，首页会提示你去看。
- 「总结」页可以按 **本周 / 上周 / 本月 / 上月 / 自定义起止** 生成任意时间段总结，
  支持**一键复制全文**、另存到 `reports/`。
- 报表是 `.md`，记事本可开。内容含：周期起止、有记录天数、自然日天数、记录率、总时长、工作时间、
  各大类合计、两种平均每天、Top 5 二级任务、达标天数/达成率/连续达标天数、与上一周期对比，
  以及一段**可直接复制的文字总结**。

## 目录结构

```

├─ 启动.bat              双击启动（纯 ASCII，避免 cmd 解析中文出错）

│   ├─ web/              前端：index.html / style.css / app.js（原生，无构建工具）
│   ├─ db.py             数据层：建表、连接、默认数据
│   ├─ util.py           时长/日期/区间并集等通用工具
│   ├─ stats.py          统计口径实现
│   ├─ goals.py          目标、达标、连续达标、计划 vs 实际
│   ├─ timers.py         计时引擎、跨午夜切分、超时确认、补录
│   ├─ maintain.py       备份、撤销、任务/标签/大类管理、记录编辑删除
│   ├─ reports.py        周报月报生成
│   ├─ xlsx.py           手写 .xlsx 导出（不依赖任何库）
│   └─ server.py         本地 HTTP 服务 + JSON 接口
├─ data/                 运行时生成：SQLite 数据
├─ backup/               运行时生成：每日备份
├─ reports/              运行时生成：周报月报
└─ export/               运行时生成：导出的 Excel
```

## 已知限制

1. **必须装 Python 3**：只用标准库，但仍然依赖 Python 本身。
2. **只在 Windows 上验证过**：`启动.bat` 是 Windows 批处理，`os.startfile` 也是 Windows 专有；
   源码本体跨平台，但没在 Linux/macOS 上测过。
3. **没有登录、没有多用户**：只监听 `127.0.0.1`，同一台电脑上其他程序理论上能访问这个端口，不做权限校验。
4. **计时显示到秒、存储到分钟**：计时中显示 `H:MM:SS` 便于看着时间走，落库按整数分钟（四舍五入）。
5. **不足 1 分钟的计时不会生成记录**（时长必须 >0 分钟）。
6. **只有时长、没有时间段的记录不能事后补时间段**，要时间段就删掉重录（否则会改变统计口径）。
7. **跨午夜切分是自动的、不可关**：一次跨午夜的计时必定记成两条。
8. **自动备份在软件打开时触发**：连续很多天不打开软件，那几天不会有备份。
9. **时区跟随系统**：所有「现在」取本机本地时间。
10. **本仓库不含任何历史数据导入功能**，数据从零开始记录。
